# 사용자 시나리오 (Dogfooding 검증용)

기획이 추상적으로 흐르지 않도록, 실제 사용자가 어떻게 쓰는지 3개 시나리오로 고정한다.
각 시나리오는 MVP 검증의 **수용 기준(acceptance criteria)** 역할도 함.

---

## 시나리오 1: 대학원생의 연구 주제 탐색

**페르소나**: NLP 박사과정 2년차, 학위논문 주제 정하는 중

**플로우**:
1. 키워드 입력: `LLM hallucination detection`
2. 지도에서 factuality evaluation, retrieval verification, uncertainty estimation, medical QA 영토 확인
3. 빈 땅 모드 토글 → "medical QA + uncertainty + retrieval verification" 사이의 공백 후보 클릭
4. 상세 카드 확인:
   - 왜 저밀도인지 (인접 클러스터 통계)
   - 대표 인접 논문 5편
   - 가능한 연구 질문 3개
   - 추가 검색 쿼리
5. 후보를 북마크 + 관련 논문 리스트 export

**성공 기준**: 한 세션(~15분) 내에 "검토할 가치 있는 후보 1개"를 찾는다.

---

## 시나리오 2: 내 아이디어를 지도 위에 올려보기

**페르소나**: 새 논문 abstract 초안을 쓴 연구자

**플로우**:
1. abstract 초안을 입력창에 붙여넣기
2. 앱이 동일 임베딩 공간으로 매핑 → 지도에 핀 표시
3. 주변 논문과의 거리, 가장 가까운 기존 연구 5편 표시
4. 차별화 분석:
   - "이 영역은 매우 붐빔 → 다음 축으로 차별화 권장: [도메인], [방법론], [평가지표]"
   - "이 영역은 비교적 비어있음 → 진입 가치 후보"
5. novelty sanity check 결과 export

**성공 기준**: 사용자가 "내 아이디어가 어디 있는지" 5분 내 파악 + 차별화 단서 1개 이상 획득.

---

## 시나리오 3: PI/교수의 분야 트렌드 확인

**페르소나**: 랩 운영 중인 교수, 다음 프로젝트 방향 모색

**플로우**:
1. 분야 선택: `multi-agent reinforcement learning`
2. 시간 슬라이더: 최근 5년 필터
3. 성장 영역(빨강) vs 정체 영역(회색) 색상 분리
4. emerging cluster 패널 → 최근 1년 내 신생 클러스터 Top 5 + 대표 논문
5. 정체 영역 중 "재발견 가치" 후보 비교
6. 랩 내부 공유용 스냅샷 URL 생성

**성공 기준**: "지금 이 분야에서 뜨는 곳 / 식는 곳"을 10분 내 정리한 보고 가능.

## 시나리오를 통한 기능 우선순위 추출

| 기능 | 시나리오 1 | 시나리오 2 | 시나리오 3 | 우선순위 |
|------|:---------:|:---------:|:---------:|:--------:|
| 키워드 검색 → 지도 | ✅ | — | ✅ | P0 |
| 빈 땅 모드 + 상세 카드 | ✅ | — | — | P0 |
| 다음 행동 제안 | ✅ | ✅ | ✅ | P0 |
| abstract 입력 → 핀 | — | ✅ | — | P1 |
| 시간 슬라이더 | — | — | ✅ | P1 |
| emerging cluster 자동 탐지 | — | — | ✅ | P2 |
| URL 공유 / export | ✅ | ✅ | ✅ | P1 |

→ MVP는 **시나리오 1을 완성**하는 것에 집중. 나머지는 Phase별 확장.
