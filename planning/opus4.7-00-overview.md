# PaperLand 기획 개요

## 한 줄 요약
**PaperLand는 논문 검색기가 아니라 "연구 지형도 + 공백 후보 탐지기"다.**
이미 점유된 연구 영토와 탐색 가치 높은 빈 영역을 함께 보여주는 웹앱.

## 정체성 (Identity)
- ❌ 또 하나의 논문 검색기가 아님
- ✅ "어디까지 연구됐고, 어디가 아직 덜 탐색됐나?"에 답하는 도구
- ✅ 단정("여기는 아무도 안 했다")이 아닌 **근거 기반 후보 제시**("수집 데이터 기준 저밀도 영역")

## 문제 정의
- 연구자/대학원생이 새로운 연구 주제를 찾을 때, "이 분야 이미 누가 했나?", "어디가 빈 영역인가?"를 파악하기 어려움
- 기존 도구(Google Scholar, Connected Papers, Semantic Scholar)는 **개별 논문 탐색**에 강점이 있지만, **분야 전체의 지형도(landscape)** 를 한눈에 보여주지 못함
- 특히 "있을 법한데 없는 영역"(blind spot)은 거의 보여주지 않음

## 핵심 가치 제안 (Value Proposition)
1. **지형도(Landscape) 시각화**: 분야 전체의 밀도를 한눈에
2. **빈 땅(Whitespace) 탐지**: 미개척 영역을 적극적으로 강조
3. **시간축 변화**: 어떤 영역이 뜨고 지는지 애니메이션
4. **개인화**: "내 관심사는 이 지도에서 어디인가?"
5. **다음 행동까지 연결**: 빈 영역 표시로 끝나지 않고 관련 논문·검색 쿼리·연구 질문 후보·검증 방법까지 제시

## 핵심 메타포
| 표현 | 의미 |
|------|------|
| **논문** | 지도 위의 점·작은 토지 단위 |
| **클러스터** | 비슷한 연구가 모인 영토 |
| **밀집 지역** | 이미 많은 연구가 진행된 포화 영역 |
| **최근 확장 지역** | 새 논문이 빠르게 늘어나는 성장 영역 |
| **저밀도 경계** | 분야가 맞닿지만 논문 수가 적은 융합 후보 |
| **고립 고영향 논문** | 인용은 많지만 후속 연구가 적은 확장 후보 |

## 타깃 사용자
- **1순위**: 연구 주제 선정 중인 박사/석사 과정생
- **2순위**: 새로운 연구 방향을 모색하는 연구자
- **3순위**: 분야 트렌드를 파악하려는 산업계/투자자

## 차별화 포인트
| 도구 | 강점 | PaperLand와의 차이 |
|------|------|---------------------|
| Connected Papers | 개별 논문의 인용 그래프 | 분야 전체 지형 X |
| Semantic Scholar | 검색·필터링 | 시각적 빈 영역 탐지 X |
| arXiv Sanity | 최신 논문 추천 | 분야 지도 없음 |
| Map of Science | 분야 지도 시도 | 정적·낡음·whitespace 미강조 |

→ **"빈 영역을 적극적으로 강조하는 동적 지도"** 라는 포지션이 비어있음.

## 관련 자산
- 사용자가 이미 보유: `arxiv-paper-scraping` 프로젝트 (논문 수집 파이프라인)
- 즉, **데이터 수집 단은 일정 부분 해결됨** → 시각화·분석·UX에 집중 가능
