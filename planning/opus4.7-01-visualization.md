# 시각화 설계

## 메타포 선택

### 후보 비교

| 메타포 | 장점 | 단점 | 적합도 |
|--------|------|------|--------|
| **2D 임베딩 + 등고선/히트맵** | 논문 의미 기반, "빈 골짜기" 자연스럽게 표현 | 축의 의미 해석 어려움 | ⭐⭐⭐⭐⭐ |
| 트리맵 (분야 위계) | 카테고리 구조 명확 | 빈 공간 표현 약함 | ⭐⭐⭐ |
| 그래프 네트워크 | 분야 간 연결성 표현 | 밀집도 직관성 ↓ | ⭐⭐ |
| 보로노이 다이어그램 | 영역 분할 명확 | 미개척지 표현 어려움 | ⭐⭐⭐ |
| 격자형 픽셀맵 (땅따먹기 그대로) | 메타포 충실, 직관적 | 좌표 기준 인위적 | ⭐⭐⭐⭐ |

### 추천: **하이브리드 — 임베딩 기반 좌표 + 격자 오버레이**

- 베이스: 논문 abstract 임베딩(UMAP/t-SNE 2D 투영)
- 오버레이: 격자(hex grid 또는 square grid)로 영역화 → "땅" 메타포 유지
- 각 셀의 색상: 논문 밀도 / 최근성 / 미개척도
- 핵심 분야명은 셀 라벨 또는 클러스터 라벨로 표시

## 시각 인코딩 (Visual Encoding)

| 시각 채널 | 표현 정보 |
|-----------|-----------|
| 위치(x, y) | 의미적 유사도 (임베딩) |
| 색상(hue) | 분야(카테고리) 또는 점유 상태 |
| 채도/밝기 | 논문 밀도 (진할수록 많음) |
| 셀 크기/높이 | 누적 논문 수 (옵션: 3D 지형) |
| 테두리 강조 | 빈 땅 / 핫 영역 알림 |
| 애니메이션 | 시간에 따른 점유 변화 |

## 인터랙션 설계

### 핵심 인터랙션
1. **줌·팬**: 거시(arXiv 카테고리) → 미시(서브토픽) 줌인
2. **셀 호버**: 대표 논문 미리보기, 키워드, 논문 수
3. **셀 클릭**: 사이드 패널에 해당 영역 논문 리스트
4. **시간 슬라이더**: 연도 변화에 따른 지형 변화 애니메이션
5. **검색**: 키워드/논문 ID 입력 → 지도에 핀 표시
6. **"내 위치 찾기"**: 내 논문/abstract 입력 → 좌표 매핑

### 보조 기능
- **레이어 토글**: 밀도 / 최근성 / 인용수 / 저자 영향력
- **필터**: 연도, 카테고리, 저자, 기관
- **빈 땅 모드**: whitespace만 강조 표시
- **북마크/메모**: 관심 영역 저장

## 기술적 고려사항

- 논문 수가 수십만~수백만 → **WebGL 기반 렌더링 필수** (deck.gl, regl, three.js)
- 임베딩 사전 계산: 백엔드에서 배치로 UMAP/t-SNE → 결과를 JSON/Parquet로 서빙
- 클러스터링: HDBSCAN 또는 BERTopic으로 토픽 라벨링
- 줌 레벨별 LOD(Level of Detail): 멀리서는 클러스터 단위, 가까이서는 개별 논문
