# 로드맵 (MVP → V1 → V2)

## Phase 0: 데이터 준비 (1-2주)
**목표**: 시각화에 쓸 깨끗한 데이터셋 확보
- [ ] arXiv 단일 카테고리(예: cs.CL) 5년치 수집
- [ ] 임베딩 모델 선정 + 배치 임베딩
- [ ] UMAP 2D 좌표 산출
- [ ] HDBSCAN 클러스터링 + 키워드 라벨링
- [ ] 결과를 노트북에서 matplotlib으로 1차 확인

**완료 기준**: 노트북에서 "그럴듯한 지도"가 보임

## Phase 1: V0 = MVP (3-4주) — 차별점 포함
**목표**: PaperLand의 핵심 가설을 가장 작게 검증. 지도만 있는 "예쁜 시각화"가 아니라 **공백 후보까지 포함**해야 V0.
상세는 [opus4.7-08-v0-scope.md](./opus4.7-08-v0-scope.md) 참조.

- [ ] Next.js + deck.gl hex 히트맵 (cs.CL 5년치)
- [ ] 줌·팬, 호버 시 셀 정보, 셀 클릭 시 대표 논문 5개
- [ ] **Adjacent Gap 중심 공백 후보 Top 10** (단일 detector)
- [ ] **공백 후보 상세 카드**: 인접 논문 5편 + 왜 후보인지 (수치 근거) + 추가 검색 쿼리
- [ ] 정적 JSON 서빙 (백엔드 최소화)

**완료 기준**: 본인이 직접 써서 "검토할 가치 있는 후보 1개"를 발굴하면 통과 (시나리오 1 충족).

## Phase 2: 빈 땅 탐지 확장 (2-3주)
**목표**: 다중 detector + 신뢰성 검증
- [ ] CrossDomainGapDetector (교차 공백)
- [ ] IsolatedHighImpactDetector (고립 고영향)
- [ ] **고급 reachability 필터** (V0의 convex hull을 합성 abstract 임베딩 매핑 검증으로 강화)
- [ ] 유형별 라벨 + 공백 후보 모드 확장
- [ ] 사용자 피드백 버튼 (`유효한 후보 같음` / `관련 연구가 이미 있음`)

**완료 기준**: 5명 정도 베타 유저에게 보여주고 "이 후보 들여다볼 가치 있어 보인다" 반응 1건 이상

## Phase 3: 시간축·개인화 (2-3주)
- [ ] 연도 슬라이더 + 셀 변화 애니메이션
- [ ] 신생/쇠퇴 빈 땅 분류
- [ ] "내 abstract 입력 → 지도 위치" 기능
- [ ] 북마크 (로컬 스토리지)

## Phase 4: 확장 (V1.0 출시)
- [ ] arXiv 전 분야 확장
- [ ] Semantic Scholar 인용수 통합
- [ ] 사용자 계정 + 클라우드 북마크
- [ ] 공유 가능한 URL (특정 영역 딥링크)
- [ ] SNS 공유용 OG 이미지 자동 생성

## Phase 5 (V2 아이디어)
- 분야별 "랜드로드" 게임화 (저자/기관별 점유 지도)
- LLM 기반 빈 영역 연구 가설 자동 생성
- 협업: 팀이 함께 영역 탐색·메모
- 학회/저널별 필터
- 한국어 논문 통합 (KCI, RISS)

## 위험 신호 (Pivot Trigger)
- Phase 1 결과가 "그냥 색 칠한 점 그래프"로 보이고 인사이트가 없으면 → 메타포 재검토
- 빈 영역이 모두 본질 공백이면 → 알고리즘 재설계 또는 도메인 축소
