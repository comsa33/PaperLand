# V0 스코프 (확정)

> **이 문서는 V0의 단일 진실 공급원(Single Source of Truth)이다.**
> 다른 문서와 충돌하면 이 문서가 우선한다.

## V0의 한 줄 정의
**cs.CL 5년치 arXiv 데이터로 만든, "Adjacent Gap 공백 후보 Top 10을 클릭해 다음 행동까지 받는" 정적 웹앱.**

## V0가 검증하는 가설
> "임베딩 기반 2D 지형도 + 인접 공백 강조"가 연구자에게 **"검토할 가치 있는 후보"** 를 5–15분 내에 제공할 수 있는가?

이 가설이 거짓이면 PaperLand는 다른 방향으로 피벗해야 한다.

## 포함 (IN SCOPE)

### 데이터
- 소스: **arXiv `cs.CL` 단일 카테고리, 최근 5년**
- 추정 규모: 수만 건
- 갱신: V0는 **정적 스냅샷**. 자동 갱신 없음.
- 저장: 로컬 Parquet/JSON. 백엔드 DB 없음.

### 파이프라인 (오프라인 배치)
- 임베딩: SPECTER2 또는 bge-large (로컬 GPU/CPU)
- 차원축소: UMAP 2D
- 클러스터링: HDBSCAN + c-TF-IDF 키워드
- 격자화: hex bin
- 빈 땅 탐지: **AdjacentGapDetector 단일** + convex hull 본질 공백 필터
- 출력 (정적, 프론트가 직접 fetch):
  - `manifest.json` (스키마 버전, 빌드 시각, 체크섬)
  - `cells.json` (hex 셀 통계)
  - `whitespace_top10.json` (공백 후보)
  - `papers_index.json` (논문 메타 인덱스 — 필요한 필드만 슬림화)
  - `cluster_labels.json`

### 프론트엔드
- Next.js + deck.gl
- 메인 화면: hex 히트맵 (밀도 색상)
- 줌·팬·호버
- 셀 클릭 → 사이드 패널: 셀 내 대표 논문 5편
- **공백 후보 모드 토글**: 후보만 강조 표시
- **공백 후보 Top 10 패널**: 좌측 또는 상단
- **공백 후보 상세 카드** (클릭 시):
  - 위치, 인접 키워드 3–5개
  - 인접 클러스터의 대표 논문 5편
  - "왜 후보인지" 수치 근거 (템플릿 텍스트)
  - 추가 검색 쿼리 1–3개 (외부 검색 링크)

### 백엔드
- **없음**. 정적 JSON을 CDN/Vercel에서 서빙.
- 어떤 동적 엔드포인트도 V0에 포함하지 않는다 (시나리오 2 / abstract 입력 / 검색 API 모두 V1+).

### UX 카피
- 사용자-facing 모든 텍스트는 `공백 후보`, `저밀도 영역`, `수집 데이터 기준` 사용
- "미개척", "비어있다", "아무도 안 했다" 금지

## 제외 (OUT OF SCOPE — V1 이후)
- ❌ Adjacent Gap 외 detector (CrossDomain, Faded, Emerging, MethodDomain, IsolatedHighImpact)
- ❌ 시간 슬라이더 / 연도 애니메이션
- ❌ 사용자 abstract 입력 → 핀 (R8 정보 유출 리스크)
- ❌ 사용자 계정·북마크
- ❌ LLM 기반 설명/연구 질문 생성 (템플릿만)
- ❌ Semantic Scholar 인용 데이터
- ❌ arXiv 다른 카테고리
- ❌ 모바일 최적화
- ❌ 공유 URL / OG 이미지
- ❌ 사용자 피드백 버튼 (V1)

## 수용 기준 (Acceptance Criteria)
V0는 다음을 모두 만족해야 통과:

1. cs.CL 지도가 hex 히트맵으로 렌더링되고, 줌·팬·호버가 작동한다.
2. 공백 후보 Top 10이 패널에 표시되고, 모든 후보는 본질 공백 필터를 통과한 상태다.
3. 후보 클릭 시 상세 카드에 (a) 인접 논문 5편, (b) 수치 근거 텍스트, (c) 검색 쿼리 링크가 모두 표시된다.
4. 모든 사용자-facing 카피가 UX 원칙(단정 금지)을 준수한다.
5. **본인이 직접 V0를 사용해 "검토할 가치 있는 후보 1개"를 발굴**한다 (시나리오 1 충족).
